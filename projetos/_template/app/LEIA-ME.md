# app/

Código e build do projeto.

O portfólio só depende de um caminho: **`app/dist/index.html`**. É esse arquivo
que o botão "Abrir demo" do card abre.

- Projeto com Vite/React: mantenha o código aqui e rode `npm run build` — o
  `dist/` sai pronto.
- Página estática única: crie `dist/index.html` na mão e pronto.
- Projeto sem demo aberta: deixe esta pasta vazia e o campo `links.demo` como
  `""` em `home/projects-data.js`. O card mostra "Case em preparação".

Apague este arquivo ao usar a pasta.
