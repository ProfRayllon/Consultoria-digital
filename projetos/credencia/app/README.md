# Credencia

Portfolio Edition de um sistema de eventos e formações: cadastro, divulgação, inscrição,
credenciamento e análise. Visão completa e modo vitrine em `../CASE.md`.

## Executar

```bash
npm install
npm run dev

http://127.0.0.1:5173
```

## Build

```bash
npm run build
npm run preview
```

## Escopo

A demo usa React, TypeScript, Vite, Tailwind CSS, Recharts e lucide-react. Todos os dados são sintéticos e ficam em `src/data/syntheticData.ts`.

A interface usa a marca `RS` em tema azul para reforçar a autoria no portfólio.
